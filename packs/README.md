# Decor packs

This folder tracks decor packs published for SuperDecor.

A **data pack** is a single `<packId>.zip` (a `manifest.json` plus `models/*.glb` plus `icons/*.png`) that drops into `<game>/BepInEx/plugins/SuperDecor/Packs/`. Build one with no code using the **[Expansion Pack Generator](https://leptoon.github.io/superdecor-release/)**.

To make a pack, see [Creating packs](../docs/CREATING_PACKS.md) (no code) or [Code packs](../docs/CODE_PACKS.md) (custom C#). The manifest schema and C# API are in the [API reference](../docs/API_REFERENCE.md).

- **First-party packs** (by Leptoon) are published as `.zip` assets on the [Releases](https://github.com/leptoon/superdecor-release/releases) page. Their decor assets are All Rights Reserved; see the root [README](../README.md#license).
- **Community packs:** authors host their own; notable ones may be linked here.

*No first-party packs are published yet; they will appear here and on the [Releases](https://github.com/leptoon/superdecor-release/releases) page as they are released.*
